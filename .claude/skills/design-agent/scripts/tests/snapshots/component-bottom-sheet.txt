## 바텀 시트 (Bottom Sheet) — 웹 컴포넌트
  쉬운 말: 「아래에서 올라오는 판」 「밑에서 스윽 나오는 거」 「모바일 공유창 같은 거」
  설명: 화면 아래에서 올라오는 판. 모바일에서 모달 대신 많이 쓴다.
  헷갈리면: 아래에서 올라오면 바텀 시트, 옆에서 밀려 나오면 드로어
  AI에게: 모바일에서 공유를 누르면 바텀 시트가 올라오게 해줘. 위에 잡는 손잡이 표시도.
  보기: https://giting.kr/menu/ui-menu/bottom-sheet  · 데모 파일 public/giting/ui-menu/bottom-sheet.html

## 바텀시트 (Bottom Sheet) — 앱 컴포넌트
  쉬운 말: 「아래에서 반쯤 올라오는 판」 「손잡이 있는 시트」
  설명: 화면 아래에서 올라오는 판. 위에 손잡이가 있고, 높이를 단계로 조절하기도 한다.
  AI에게: 필터를 바텀시트로. 반높이·전체높이 두 단계, 위 손잡이로 끌어 조절, 바깥 탭하면 닫힘. 안에 입력칸이 있으면 키보드가 올라올 때 시트째 그 위로.
  보기: https://giting.kr/menu/app-menu/bottomsheet

## 드로어 (Drawer / Side Panel) — 웹 컴포넌트
  쉬운 말: 「옆에서 미끄러져 나오는 메뉴」 「햄버거 누르면 나오는 거」 「슬라이드 패널」
  설명: 화면 옆에서 서랍처럼 밀려 나오는 판.
  헷갈리면: 옆에서 밀려 나오면 드로어, 아래에서 올라오면 바텀 시트, 항상 붙어 있으면 사이드바
  AI에게: 햄버거 버튼을 누르면 오른쪽에서 드로어 메뉴가 나오게 해줘. 배경 누르면 닫히게.
  보기: https://giting.kr/menu/ui-menu/drawer  · 데모 파일 public/giting/ui-menu/drawer.html
