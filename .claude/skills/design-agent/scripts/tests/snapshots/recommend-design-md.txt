# 데스크톱 · 매일 쓴다 · 내 기기 · 표·숫자 중심

## 화면 구조
- 내비게이션: 왼쪽 고정 사이드바
- 확인 단계: 되돌릴 수 없는 작업 앞에서만 확인

## 꼭 지킬 것 — 규격·접근성 기준이 있다
- 키보드 포커스가 눈에 보여야 한다 (WCAG 2.2 · 2.4.7)

## 보통 이렇게 — 흔히 이렇게 한다. 이유가 있으면 바꿔도 된다
- 꼭 필요한 동작을 hover 뒤에 숨기지 않는다
- 화면이 넓어도 본문 폭은 제한한다
- 익숙해진 아이콘은 라벨 없이 써도 된다
- 자주 하는 동작에 키보드 단축키를 준다
- 상태를 한 화면에 모아 보여준다. 페이지를 오가게 하지 않는다
- 숫자는 고정폭(tabular-nums)으로 오른쪽 정렬
- 정보가 많은 화면은 바깥 여백·카드 간격·버튼 높이를 줄여 촘촘하게 둔다. 일반 웹페이지 여백을 그대로 쓰지 않는다 (Madia Designer 「AI디자이너」 1부 7:00)
- 단위는 셀마다 쓰지 말고 열 제목에

## 참고
- 표 행에 hover 배경을 주고 행 전체를 클릭 영역으로
- 하다 만 작업을 다음에 이어서 할 수 있게
- 정렬·필터는 표 바로 위에

## 패턴별 방식
- 불러오는 동안 (다시 하면 그만인 작업 기준): 스켈레톤 — 표·숫자 중심: 행 모양을 미리 보여준다
- 버튼을 누른 뒤 (다시 하면 그만인 작업 기준): 버튼 안 스피너 — 다시 하면 그만인 작업: 실패해도 다시 누르면 그만이다
- 비어 있을 때: 다음 행동 버튼 — 
- 실패했을 때 (다시 하면 그만인 작업 기준): 토스트 — 매일 쓴다: 흐름을 끊지 않는다
- 끝났다고 알릴 때 (다시 하면 그만인 작업 기준): 토스트 — 매일 쓴다: 자주 하는 일은 가볍게 / 다시 하면 그만인 작업: 가벼운 일은 가볍게 알린다
- 새 소식 알릴 때: 숫자 배지 — 매일 쓴다: 일을 끊지 않고 나중에 몰아 본다
- 처음 안내: 안내 없음 — 매일 쓴다: 알아서 쓴다
- 목록이 길 때: 페이지 번호 — 데스크톱 / 표·숫자 중심
- 새로 고칠 때: 새로고침 버튼 — 데스크톱 / 매일 쓴다: 언제 받은 정보인지 시각으로 본다
- 카테고리 이동: 상단 탭 — 데스크톱: 분류가 몇 개뿐일 때
- 거르기: 옆 패널 — 데스크톱 / 매일 쓴다: 여러 조건을 오가며 비교한다
- 화면 사이 이동: 왼쪽 사이드바 — 데스크톱: 넓은 화면에서 메뉴가 늘 보인다
- 찾기: 펼친 검색창 — 데스크톱 / 매일 쓴다: 자주 찾는 사람은 바로 쳐서 간다
- 가벼운 메뉴 열기: 누른 자리 옆 레이어 — 데스크톱: 누른 자리 옆에 뜨고 바깥을 누르면 닫힌다 / 매일 쓴다: 열고 닫기가 가볍다
- 하나 고르기: 라디오 목록 — 조건과 직접 걸리는 근거 없음, 가장 흔한 방식
- 수량: 숫자 입력 — 매일 쓴다: 큰 숫자를 빠르게
- 켜고 끄기: 토글 스위치 — 조건과 직접 걸리는 근거 없음, 가장 흔한 방식
- 입력 확인 시점 (다시 하면 그만인 작업 기준): 입력하는 동안 — 조건과 직접 걸리는 근거 없음, 가장 흔한 방식
- 올리기 (다시 하면 그만인 작업 기준): 끌어 놓기 칸 — 데스크톱: 파일이 바탕화면·폴더에 있어 끌어 놓기 쉽다
- 지울 때 (다시 하면 그만인 작업 기준): 지우고 되돌리기 — 매일 쓴다: 묻는 단계 없이 빠르게 / 다시 하면 그만인 작업: 휴지통처럼 되살릴 수 있는 삭제
- 확인 단계 모양 (다시 하면 그만인 작업 기준): 대화상자 — 데스크톱
- 주요 버튼 자리: 내용 옆 오른쪽 — 데스크톱: 눈이 내용을 다 읽고 끝나는 자리
- 장바구니·합계 자리: 오른쪽 패널 — 데스크톱
- 여러 단계 흐름 (다시 하면 그만인 작업 기준): 한 화면에 펼치기 — 매일 쓴다: 앞뒤로 오가지 않고 한눈에 / 데스크톱: 넓은 화면을 쓴다
- 긴 글 (다시 하면 그만인 작업 기준): 말줄임 — 표·숫자 중심: 표 안에서는 한 줄 / 매일 쓴다
- 사진이 없을 때: 자리를 없앤다 — 표·숫자 중심
- 상태 표시: 점 + 글자 — 매일 쓴다: 목록이 덜 무겁다
- 시간 표기 (다시 하면 그만인 작업 기준): 경과 + 시각 — 매일 쓴다

## 디자인 시스템 기준
- 불러오는 동안: 1초 안에 끝나면 로딩 표시를 하지 않는다. 깜빡이는 것이 더 느리게 느껴진다 (당근, KRDS, Primer, Ant)
- 불러오는 동안: 기다리는 시간으로 고른다. 짧으면 스피너·스켈레톤, 3~4초를 넘으면 진행 바와 안내, 아주 길면 뒤에서 처리하고 취소를 준다 (당근, Primer)
- 불러오는 동안: 가능한 한 빨리 무엇이든 보인다. 빈 화면은 고장 난 것처럼 보인다 (Apple)
- 불러오는 동안 › 스켈레톤: 목록·카드·표처럼 틀이 정해진 곳에만. 정적인 것·버튼·모달에는 쓰지 않는다 (Carbon, 원티드, 당근)
- 버튼을 누른 뒤: 보내는 버튼은 두 번째 누름을 무시한다. 서버에서도 막는다 (KRDS, GOV.UK, Carbon)
- 버튼을 누른 뒤 › 버튼 안 스피너: 한 부분만 처리 중이면 그 자리(버튼 안)에 표시한다 (Carbon, KRDS)
- 비어 있을 때: 처음이라 비었는지, 검색·필터 결과가 없는지, 오류인지에 따라 문구를 다르게 쓴다 (Carbon, Shopify, 당근)
- 비어 있을 때 › 다음 행동 버튼: 다음에 할 일이 있으면 버튼 하나를 둔다. 막다른 길을 만들지 않는다 (Carbon, 당근, 원티드)
- 비어 있을 때 › 다음 행동 버튼: 빈 화면 컴포넌트(Empty)에 그림·제목·설명·행동 버튼 자리를 둔다 (shadcn)
- 실패했을 때: 오류가 여러 개면 위에 오류 목록을 두고 누르면 그 칸으로 간다 (GOV.UK, Primer)
- 실패했을 때 › 토스트: 오류에는 쓰지 않는다. 중요한 메시지는 저절로 사라지면 안 된다 (Shopify, Carbon, Atlassian, Fluent)
- 끝났다고 알릴 때: 토스트를 쓰지 않는 곳도 있다(스크린리더가 놓친다). 그 자리 문구나 띠로 알린다 (Primer)
- 끝났다고 알릴 때 › 토스트: 방금 한 일의 짧은 성공 확인용. 한 줄로, 저절로 사라지게 (KRDS, 원티드, Shopify, Fluent)
- 새 소식 알릴 때 › 숫자 배지: 중요한 정보에만. 광고에 쓰지 않는다 (Apple)
- 처음 안내: 온보딩은 건너뛸 수 있으니, 주요 기능은 빈 화면 안내를 따로 둔다 (Carbon)
- 목록이 길 때 › 페이지 번호: 검색 결과·게시판처럼 위치를 알아야 할 때. 한 화면 분량이면 나누지 않는다 (당근, KRDS, GOV.UK, Ant)
- 화면 사이 이동 › 왼쪽 사이드바: 태블릿·데스크톱은 왼쪽 레일이나 사이드바. iPad는 탭바를 사이드바로 바꿀 수 있게 (Material, Apple)
- 가벼운 메뉴 열기: 데스크톱의 무거운 하위 작업은 옆에서 밀려 나오는 서랍으로 (Ant)
- 가벼운 메뉴 열기 › 누른 자리 옆 레이어: 데스크톱에서 가벼운 확인·메뉴는 누른 자리 옆에 (Ant)
- 수량 › 숫자 입력: 범위가 넓을 때(나이처럼) (KRDS)
- 켜고 끄기 › 토글 스위치: 바로 적용되는 설정에 (당근, KRDS, Primer)
- 지울 때 › 지우고 되돌리기: 되돌릴 수 있으면 묻지 말고 되돌리기를 준다 (Apple, 당근)
- 확인 단계 모양 › 대화상자: 버튼은 3개 이내. 안에 폼·탭 같은 무거운 것을 넣지 않는다 (Apple, Fluent, KRDS)
- 주요 버튼 자리: 가장 강조한 버튼은 한 화면에 하나. 위험한 동작만 빨간색 (당근, KRDS)

## 쓰지 말 것
- 보라→파랑 그라데이션 히어로
- 모든 블록에 같은 radius·그림자를 준 카드
- 이모지를 섹션 표시로 쓰기
- 순서가 없는 내용에 01 / 02 / 03 번호
- 무조건 가운데 정렬
- 아무 근거 없이 고른 Inter 한 가지 서체
- 색 기운이 없는 순수 회색(#888 계열)
- "강력한", "원활한" 같은 과장 문구
- 카드·버튼·탭마다 넣은 안쪽 그림자·빛 번짐·그라데이션
- 모든 글자를 굵게. 굵기와 크기로 위계가 서지 않는다
- 같은 종류 항목(알림 카드 등)마다 다른 배치
- 테두리도 그림자도 없이 떠서 경계가 안 보이는 레이어
- 예시 그림·미리보기마다 크기와 자리가 제각각(어떤 건 카드 폭을 채우고 어떤 건 한쪽에 붙음)
- 카드 안에 테두리 상자, 그 안에 또 회색 상자를 겹치기
- 제목과 본문이 거의 같은 크기이고 나머지는 전부 작은 회색 글
- 출처·보조 링크까지 모두 강조색이라 진짜 이동할 곳이 묻힘
- 상태(품절·마감·오류)를 색만으로 구분하기. 글자나 아이콘을 같이 쓴다
- 보라를 피해 고른 다음 기본값: 크림 바탕에 테라코타 강조, 아주 어두운 바탕에 네온 한 가지
- 둥근 카드 한쪽에 두꺼운 색 띠
- 목적 없는 반투명 흐림(글래스) 카드. 뒤에 따라 글자 대비가 바뀐다
- 제목마다 위에 붙인 자간 벌린 작은 대문자 소제목
- 한글 옆 이탤릭, 영문 기준으로 좁힌 한글 행간(본문 1.5 미만)
- 근거 없는 큰 숫자("10,000%"), "A가 아니라 B" 문장, 대시(—) 남발
